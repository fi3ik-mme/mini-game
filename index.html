Як встановити додаток на телефон?

🤖 Android — окремий APK-файл: натисни «Завантажити для Android». Після завантаження відкрий файл → дозволь «Встановлення з невідомих джерел» (Settings → Security) → встанови. Працює без Google Play та без інтернету після першого запуску.

🤖 Android — через браузер (PWA): Відкрий посилання у Chrome. Зʼявиться банер «Встановити додаток». Або: меню (⋮) → «Встановити додаток» / «Додати на головний екран».

📱 iPhone / iPad: Відкрий посилання у Safari → натисни «Поділитися» ⬆️ → «Додати на головний екран» (Add to Home Screen).

💻 Комп'ютер: Chrome / Edge — у адресному рядку буде значок «Встановити» (⊕).

✓ Після встановлення можна грати без інтернету — усі ігри та питання зберігаються на пристрої.
